# Week 7 Dataset Validation, Identity Tracking and Behaviour Preparation

## Objective

The main goal of Week 7 is to improve the reliability of the data pipeline before behaviour classification. The critical bottleneck is the association between pig, colour marker, stable identity, and behaviour label.

## Main workflow

1. Week 6 input audit.
2. Region of Interest and crate mapping.
3. Ground truth dataset statistical analysis.
4. Colour marker rule definition.
5. Scanpoint colour assignment baseline.
6. Long-term tracking.
7. Track ID and colour ID fusion.
8. Improved visualization interface.
9. Dataset splitting strategy analysis.
10. External dataset validation.
11. Behaviour feature representation analysis.
12. Clip-level behaviour representation.
13. Scene-change detection.
14. Compliance and quality audit.
15. Final package and presentation update.

## Rule

No major limitation should be silently left unresolved. If data, package, model weights, or human confirmation are needed, they must be explicitly requested and tracked.
