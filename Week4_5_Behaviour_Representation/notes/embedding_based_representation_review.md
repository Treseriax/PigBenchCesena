# Embedding-Based Representation Review

## Purpose

This review evaluates whether visual embeddings can represent pig behaviour beyond hand-crafted trajectory, ROI, social-spatial, skeleton, and mesh features. Embeddings are not implemented at this stage; they are evaluated as a future feature layer.

## Feature levels

| feature_level              | input                                                        | aggregation                                   | possible_use                                            |
|:---------------------------|:-------------------------------------------------------------|:----------------------------------------------|:--------------------------------------------------------|
| Frame-level crop embedding | Single pig crop from one frame                               | None or average over nearby frames            | Visual posture/appearance clustering                    |
| Track-level embedding      | All crops belonging to one track ID                          | Mean, median, or temporal pooling             | Track identity consistency, ReID, appearance comparison |
| Segment-level embedding    | All frame or track embeddings within one scan-window segment | Mean pooling, histogram, cluster distribution | Segment-level behaviour representation                  |
| Clip-level video embedding | Short video clip or fixed-length frame sequence              | Temporal model output                         | Aggression, interaction, or movement classification     |
| Hybrid representation      | Trajectory + ROI + visual embedding                          | Concatenate normalized feature groups         | Future interpretable + visual behaviour classifier      |

## Risks and mitigation

| risk                 | explanation                                                                      | mitigation                                                                                              |
|:---------------------|:---------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------|
| Low interpretability | Embedding dimensions are not directly meaningful like speed or ROI time.         | Use embeddings together with interpretable trajectory and ROI features.                                 |
| Domain shift         | Models pretrained on generic images/videos may not fit overhead pig-pen footage. | Validate on Unibo and Edinburgh samples; use clustering and manual inspection before relying on labels. |
| Label scarcity       | Good supervised embeddings require reliable behaviour labels.                    | Start with self-supervised or pretrained embeddings; fine-tune only after stronger labels exist.        |
| Track fragmentation  | Embedding aggregation over wrong track IDs can mix identities.                   | Use conservative identity handling and track quality filtering.                                         |
| Computational cost   | Video embeddings and large models can be GPU-heavy.                              | Start with small samples and crop-level embeddings before full video processing.                        |

## Recommendations

|   rank | recommendation                                                           | reason                                                                                            |
|-------:|:-------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
|      1 | Do not start with embeddings as the primary representation               | Trajectory, ROI, and social-spatial features are already implemented and more interpretable.      |
|      2 | Use embeddings as a complementary feature layer                          | Visual embeddings can capture posture/appearance patterns that hand-crafted motion features miss. |
|      3 | Start with crop-level or track-level embeddings before full video models | Crop/track embeddings are easier to integrate with existing detection and tracking outputs.       |
|      4 | Use video embeddings later for temporal behaviours                       | Clip models are more appropriate for aggression, interaction, and rapid behaviour changes.        |

## Interpretation

Embedding-based representations are promising because they can capture appearance, posture, context, and temporal cues that are difficult to hand-design. However, they are less interpretable and may suffer from domain shift. For this project, embeddings should be treated as a complementary future layer. The immediate priority remains trajectory, ROI/resource, and social-spatial features, followed by skeleton/keypoint feasibility testing.
