## Edinburgh dataset extracted facts

- The Edinburgh page describes 23 days over 6 weeks of daytime pig video.
- The video was captured from a nearly overhead camera.
- Registered colour and depth videos are available.
- Most frames show 8 pigs.
- Ground-truth data includes axis-aligned bounding boxes, persistent tracking identifiers, and behaviour labels.
- The page states a total of 7200 labelled frames, each with 8 labelled pigs.
- Each clip folder contains `color.mp4`, `depth.mp4`, and `output.json`.
- Each subfolder is described as one 5-minute video clip with 1800 frames.

## Aggressive pig/chicken dataset extracted facts

- The GitHub repository contains only README and metadata.
- The README provides Baidu Pan links and password `1234`.
- The main dataset is associated with the paper *Efficient Aggressive Behavior Recognition of Pigs Based on Temporal Shift Module*.
- Additional links mention pig lying/standing/sitting posture data and caged chicken feeding data.
- Full structure and annotation format require manual or successful Baidu download.

## Current decision

The Edinburgh dataset is the stronger immediate target for structured inspection because its source page already describes video files, JSON annotations, tracking IDs, and behaviour labels. The aggressive pig/chicken dataset remains useful as a video-classification reference, but full inspection depends on successful download from Baidu Pan.
