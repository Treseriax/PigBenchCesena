# Behaviour Representation Survey

## Purpose

The goal of this survey is to compare behaviour representation families before training a final classifier. The focus is on what information can be extracted from videos, tracking outputs, ROIs, pose, mesh, and embeddings to represent pig behaviour in an interpretable and transferable way.

## Recommendation ranking for next phase

|   rank | recommended_family                  | reason                                                                                                   | next_action                                                                                 |
|-------:|:------------------------------------|:---------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------|
|      1 | Trajectory + group-spatial features | Already available from tracking outputs; interpretable; directly implemented and visualized              | Add smoothing/outlier filtering and compare features across behaviour-labelled scan windows |
|      2 | ROI / resource-based features       | Strong interpretability and directly connected to ethological resource-use concepts                      | Refine ROI definitions and later add head/snout/keypoint information if possible            |
|      3 | Skeleton/keypoint features          | Best next step for posture and head-orientation features, especially feeding/drinking and lying/standing | Review DeepLabCut, SLEAP, Animal-Pose/AP-10K and estimate annotation effort                 |
|      4 | Embedding-based crop/clip features  | Useful for future classification and transfer learning, but less interpretable                           | Start with detector crop embeddings or DINOv2-style image embeddings after feature survey   |
|      5 | Mesh-based features                 | Powerful but heavy; currently better as feasibility discussion than implementation                       | Summarize AniMer/SMAL and discuss pig/livestock applicability                               |

## Interpretation

For the immediate next phase, trajectory, ROI, and social/group-spatial features are the strongest candidates because they can be extracted from the current Unibo tracking outputs. Skeleton and embedding representations are promising next steps but require either keypoint estimation or additional feature extraction pipelines. Mesh-based representations are scientifically interesting and may provide richer posture information, but they are computationally heavier and should remain a feasibility review at this stage.

## Connection to completed work

- Trajectory features were already extracted from the corrected Unibo scan-window tracking outputs.
- ROI/resource-style features were implemented as a first centroid/bbox-based prototype.
- Edinburgh annotation inspection showed a clean public reference format with persistent objects, bounding boxes, and behaviour labels.
- Unibo remains the primary project dataset for representation feature engineering.
